# WordPress — landing page i kontrola wydajności

WordPress landing and conversion workflow for a local service business running Google Ads.

## Problem

Projekt łączy stronę docelową dla kampanii Google Ads z formularzem wyceny oraz poprawkami technicznymi dla ruchu przychodzącego z reklam.

## Jak działa projekt

1. Wtyczka rejestruje shortcode i renderuje własny landing. Ładuje zasoby potrzebne dla widoku.
2. Formularz przyjmuje zapytanie, wykonuje walidację po stronie WordPressa i przekazuje poprawny kontakt do poczty.
3. Osobne funkcje dodają dane strukturalne i poprawki wybranych nagłówków oraz HTML. Skrypty i style obsługują zachowanie mobilne strony.
4. Zmiany dotyczą witryny i obsługi zapytania. Dane o wzroście konwersji wymagają niezależnej analizy kampanii.

## Technologie

PHP, WordPress, JavaScript, HTML i CSS.

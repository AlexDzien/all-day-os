# Prototypy CRM — klienci, szanse i zadania

Evolution of customer-management prototypes from static workflows to a database-backed PHP application.

## Problem

Przed rozbudowaną wersją CRM powstawały prostsze prototypy badania przepływu pracy. Łączyły widoki klientów, szans sprzedażowych, kalendarza, notatek i zadań.

## Jak działa projekt

1. Statyczne widoki pozwalały sprawdzić układ nawigacji i powiązania pomiędzy kartą klienta a tablicą sprzedaży.
2. Wariant PHP wydzielił kontrolery, widoki i modele klientów oraz szans. Schemat SQL opisał trwałe dane.
3. Szkielet TypeScript rozdzielił frontend, backend i współdzielone typy w monorepo.
4. Publiczne [All Day OS](https://github.com/AlexDzien/all-day-os) pokazuje późniejszy, samodzielny wariant demonstracyjny z pełniejszym procesem.

## Technologie

HTML, CSS, JavaScript, PHP, SQL i TypeScript.

## Zakres weryfikacji

Schemat SQL wiąże rekordy klientów i szans sprzedażowych. Statyczne widoki i szkielet monorepo dokumentują wcześniejsze etapy prototypowania.
